Paper research

The canonical register holds 78 requirements, one row each: the requirement, its status, the gate that blocks it, the number that would clear it, the current number, and the file that proves it. It is read from nfl-market-desk/data/decision_readiness.csv ↗.

Two other registers exist in the repository — the Own5 hub register (80 rows) ↗ and the command desk register (73 rows) ↗. They are published separately. A combined completion count is deliberately not published: the crosswalk between the registers has not been verified row by row, and adding three registers of different shapes would produce a number nobody could check.
