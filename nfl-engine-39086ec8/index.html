What changed in this session

Found: game-line prices ARE officially readable

A prior desk concluded that no official market price exists. That was too strong: the operator's public event pages served a readable Game Lines block for 13 of the 14 Week 10 games. The first price store in this repository now exists, and the store immediately shows what is still missing — the opening number and any history.

Found: the inherited depth metric cannot rank a game

The depth column is 0 for 698 of 705 slots and 1 for the rest. It records that a replacement happened, never how deep it went. 3 slots in this desk's replacement metric now carry the rung, the cascade count and an exhaustion flag.

Found: the strongest published correlation is a bye-week artefact

Rest differential vs home margin is published as r = −0.4257. Removing the 16 games where either side came off a bye drops it to r = +0.0387 (p = 0.72). See Correlations.
