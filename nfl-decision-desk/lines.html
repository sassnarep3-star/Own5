How the line is built

  1. Ratings. Ridge least squares on final margins, margin = rating_home − rating_away + hfa, fitted only on games before the week being priced. Shrinkage keeps early-season ratings honest.
  2. Totals. Two-way points model, points = μ + offence_team − defence_opponent, same walk-forward rule.
  3. Injury adjustment. The lineup-deficiency gap is regressed on margin controlling for prior scoring margin; the coefficient is applied to the current week's gap.
  4. Market comparison. Edge = model margin − aggregator expected home margin. An edge is a research candidate, never a bet instruction.

Home-field advantage estimated at 1.21673 points on this build; the injury coefficient is -0.0391315 points per percentage point (SE 0.00975845, p 6.07152e-05, n 887).
