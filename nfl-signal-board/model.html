Model & luck panel

The evaluation is walk-forward: a rating and a scoring model are updated game by game, and each forecast is made before the result is seen. Tuning reads only the training window (2015–2024). The holdout (2025–2026) is scored once and never used to choose anything.

1. Proper scores

Side benchmark. A spread bet is a coin flip at the closing line by construction: the operator sets the line at its own median, so P(cover) is 0.5 before the vig. That makes 0.5 the assumption-free benchmark, and it is what the model is scored against. Moneyline benchmark. The de-vigged closing moneyline. Totals. The pinned corpus carries closing totals but no over/under prices, so no market probability can be formed; the total is therefore scored on point error and is explicitly not comparable to the probability scores.

4. What would have to change

FindingWhat would overturn it
Side skill of -0.0354 A model whose cluster lower bound on skill is above 0 out of sample. On this data the bound is -0.0508, so the answer is not "close".
Calibration slope 0.110 A refit with a richer feature set that moves the slope toward 1 on data the fit has not seen.
The 0.42-point total bias A pre-registered 2026-only test whose interval spans zero. The hypothesis has already seen the holdout, so it needs a fresh registration.
