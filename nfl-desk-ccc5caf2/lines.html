Model method (published so it can be audited and reproduced)

  • Inputs (official): points for (PF) and points against (PA) per club from the nfl.com 2026 regular-season standings; games played from the same table.
  • Offensive strength = PF / games; defensive strength = PA / games (lower is better).
  • Expected points (home) = (home PF/G + away PA/G) / 2; expected points (away) = (away PF/G + home PA/G) / 2.
  • Fair spread (home point of view) = expected home − expected away + HFA (+1.22; neutral site = 0). Negative = away team favoured.
  • Fair total = expected home + expected away.
  • Fair moneyline derived from the fair win probability implied by the fair spread (logistic conversion), vig-free.
  • Order: side (spread) first, then total, then moneyline — as required.

This is the singles-only shadow baseline: a simple, pre-registerable team-strength model. It is not injury-adjusted (availability features are tracked separately on injuries.html) and not validated as an edge. Market comparison is impossible until a closing-price source exists (F01/F02).
