## Issues found and corrected before release

1. **Margin-median indexing:** an initial derived spread used the array index instead of the signed margin. Caught during integration inspection, corrected to subtract the 100-point offset, and covered by a regression assertion. Rebuilt all lines afterward.
2. **Neutral-site inference risk:** only the explicitly labeled Madrid game is marked neutral. Other games now retain `null` rather than an inferred false value.
3. **Floating-point test assertions:** exact equality was replaced with tolerance checks for Wilson/calibration/joint-bound arithmetic.
4. **Schedule source linkage:** the audit now accepts the exact official per-game URL inside the frozen schedule excerpt while retaining the S11 source registration.
5. **Generated bytecode:** accidentally tracked Python bytecode was removed from Git and ignored.
6. **Concurrent-session merge conflicts:** `origin/main` advanced with five other sessions while this work was in progress. Main's shared files were preserved; this session's conflicting generated tables were namespaced under `data/own5_desk/`, and the desk was published additively at `own5-desk/`. No existing live dashboard was overwritten.
7. **Pages configuration permission:** an external API attempt to switch Pages to Actions deployment returned 403. Because Pages already serves `main` at root for other sessions, the final design keeps legacy Pages and commits the verified desk to `own5-desk/`. The workflow checks that the committed desk matches the deterministic build and smoke-checks the public URLs after merge.
