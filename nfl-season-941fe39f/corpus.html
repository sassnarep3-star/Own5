Corpus

The backtest corpus is a single pinned tarball with a published hash. Anyone can re-fetch the same bytes and rebuild every number on this site. The 136-game log the brief names is reconciled into it, game for game.

The corpus is a public mirror of the league's own game statistics and of operator closing lines. It is not the league's own feed, and the difference matters: the desk calls these "market lines from the corpus", never "the official price".

Each check is written to fail loudly. The first compares every row of the 145-game official feed this repository already held against the corpus; the second re-derives each club's record and points from the corpus and reconciles every difference to a named game; the fourth tests the league's dated schedule announcement against the live schedule facts. Full row-level detail is in the committed crosschecks.csv.

The brief's 136-game log

The brief refers to a 136-game log. The file it points at holds 145 final rows, and the count is published as 145 rather than 136. All 145 match the corpus exactly, on both scores, so the log is not merely carried forward: it is verified against an independent source and then absorbed.
