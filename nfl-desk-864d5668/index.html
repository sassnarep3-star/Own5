What this site is

A line-originating laboratory. It takes official NFL results, builds its own team ratings and its own game lines, then puts every candidate strategy through a fixed set of validation gates designed to strip out luck. There is no market price anywhere in here, because no official NFL source publishes one — that gap is flagged rather than filled.

How to read any table on this site

  • Every row ends with a link to the official page that row came from.
  • A dash in a cell means no official source published that value. It is never a guess, never an average and never a model output standing in for data.
  • Anything we cannot confirm lives on the Flagged for review page.
