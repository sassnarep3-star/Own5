# Removing Luck from the Equation (T6)

Status: done | Owner: session arena-f1d30421 | Verified: 2026-11-02

A betting result is a sum of skill and noise: `observed edge = true edge + luck`. This document is
the toolkit that separates them. All computed values are in
[`data/luck_skill.csv`](../data/luck_skill.csv) (generated by
[`scripts/compute_analysis.py`](../scripts/compute_analysis.py); exact binomial and power-analysis
math, no simulation approximations where exact answers exist).

## 2. How often does pure luck look like skill? (exact binomial)

For a bettor whose *true* win rate is break-even (52.38%), probability of observing ≥ 55%:

| n bets | P(looks like 55%+) |
|---|---|
| 50 | 35.6% |
| 100 | 26.7% |
| 200 | 20.8% |
| 300 | 19.8% |
| 500 | 13.0% |
| 1,000 | 5.2% |

Reading: one season of NFL bets (~250) still gives a break-even bettor a ~1-in-5 chance of posting
a "55% season". **Single-season ROI can never certify skill** — this is why gate G1 is an *entry*
requirement and G2/G3 carry the certification.

## 3. How much evidence does real skill need? (power analysis)

Bets required to detect true skill at 80% power, one-sided α = 0.05 against 52.38%
(normal approximation, computed):

| True skill | Bets required |
|---|---|
| 53.0% | 40,224 |
| 54.0% | 5,875 |
| 55.0% | 2,243 |
| 56.0% | 1,173 |

NFL markets: ~270 bets/season at one unit/game. A 55% bettor needs **~8 seasons** of flat betting
to be statistically distinguishable from break-even at 80% power. Consequences baked into the
system:

1. **Multiple-testing correction** (Bonferroni, gate G2) — the best of k tried strategies gets a
   luck-inflated score; we require p < 0.05/k. (Bailey, Borwein, López de Prado & Zhu 2014 show
   dozens of random trials can mint a "Sharpe 1" strategy: [Notices AMS 61(5)](https://www.davidhbailey.com/dhbpapers/overfit-tools-at.pdf);
   Deflated Sharpe Ratio: Bailey & López de Prado 2014, [JPM 40(5)](https://doi.org/10.3905/jpm.2014.40.5.094).)
2. **CLV gate (G3)** — closing-line value converges in far smaller samples than ROI and is the
   accepted leading indicator of true edge (see validation-gates.md G3 sources).
3. **Deflated leaderboard scoring** — ranking blends ROI with sample size and number of variants
   tried (leaderboard.md), so a lucky 20-bet run cannot top the table.
4. **Bayesian shrinkage on displayed performance** — leaderboard shows shrunk win rates
   (Beta prior at break-even), so small samples render near 52.4% rather than 65%.
5. **Bankroll discipline** — fractional Kelly (quarter-Kelly default) per Thorp,
   *The Kelly Criterion…* (2011, [record](https://ideas.repec.org/h/wsi/wschap/9789814293501_0054.html));
   full Kelly over-bets when the edge estimate is noisy.

## 4. Applied luck-removal: the opening catalog

* S2 (home dog ≥7) posted 56.37% over 793 bets — impressive until the family-wise correction is
  applied (needs p < 0.00625; measured 0.0134). **Verdict: luck not excluded → stays Candidate.**
* All other catalog entries fail earlier gates (see validation-gates.md).
* The system's first leaderboard therefore has zero "validated skill" entries by design — promotion
  happens only via live CLV + corrected significance.

## 5. What we deliberately do NOT do

* No cherry-picking seasons (era splits pre-registered, gate G4).
* No stopping rules ("stop when ahead") — sample sizes fixed at strategy definition.
* No refitting on the test window (walk-forward only).
* No silent deletion of losing variants — all 8 pre-registered variants published with outcomes.
