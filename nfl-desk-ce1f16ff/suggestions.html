Pick a path before anything is implemented

These are proposals, not work. Every row states the options, what each costs, and what changes on the site if it is chosen; nothing below has been implemented from its own entry, and the state column says so. The value of writing suggestions this way is that a reviewer can answer A, B or C without opening a spreadsheet.
