Nothing is awarded this week. The leaders in both divisions fail the same two gates, and a prize for the best of a set that is indistinguishable from luck would be a misleading prize.

Two rankings, because one number cannot answer two questions

The signal table asks: is the disagreement with the market right? It is stake-independent — no price, no fraction, no bankroll. The staking table asks: given that signal, how was money deployed, and what did the path look like? Ranking those two against each other is how a lucky three-leg run gets mistaken for skill, so the board shows both and prints their disagreement instead of resolving it.
