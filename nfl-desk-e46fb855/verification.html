How this desk verifies

The rules this desk is held to, and what is re-proven on every build.

Rule 1. Every body row on every page ends in a source cell: a link to the official page the value was read from, or an explicit UNVERIFIED badge. verify.py walks the generated HTML — not the CSVs — and fails the build if a row has neither.
Rule 2. A value that cannot be confirmed from an official source is left blank and flagged. It is never inferred, never averaged in and never carried over from a third party.
Rule 3. The whole desk rebuilds deterministically from the pinned captures. Running the build twice must produce byte-identical output, and the committed artefacts must match, so a silent drift fails the workflow.
Rule 4. Internal links are checked. A page that links to a page that was not generated fails the build.
