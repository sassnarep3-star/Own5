# San Francisco rental increase review

Static, anonymized evidence brief for the two reported units. Start at `index.html`; pages include Rules & practice, Unit scenarios, Flagged for review, and Official sources.

## Scope and limitations

The reported household initials are deliberately omitted. User-provided dates, amounts, location, and construction year are retained but marked unverified. Official legal values link directly to primary government sources. Empty amount cells mean no lawful amount was verified from the supplied facts. This is not legal advice or an individualized lawyer opinion. Verify current rules before serving any notice.

The repository itself contains extensive unrelated NFL/NBA research. This task's site is isolated in `rental-increase-sf/` to avoid modifying those existing research products or generated root navigation. The existing GitHub Pages configuration may expose this folder at `/Own5/rental-increase-sf/` once published from the repository's configured Pages source.
