Official inputs only, with n on every value

The brief now requires correlations to be computed only from officially sourced numbers, with the sample size published alongside each value. Every pair below is computed from numbers published by nfl.com — the 32-row league standings page, or the 137 official game results in this desk's feed. Each row states r, its p-value, a 95% interval, n and what n counts.

That rule has a cost, and it is worth being explicit about it: the official set is smaller and narrower than what this repo published before, because the previous values were computed from a third-party mirror. They have not been deleted — they are listed in the withheld register below, with the basis that disqualifies them.

What is still missing

The correlations that matter most to this project — the joint behaviour of two player-prop legs in the same game, which is what prices a same-game parlay — cannot be computed at all from official inputs available here, because no official source publishes player-prop lines or outcomes at that granularity. Gate G7 therefore fails for every parlay and prop-combination family, and the desk refuses to price a leg pair it cannot measure (F-08).
