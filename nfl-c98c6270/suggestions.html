How to use this page

Every suggestion below is a proposed path, not a decision and not an implementation. Each one carries the problem it solves, two or three options, a recommendation, and an explicit "what would change the call" so the recommendation can be falsified rather than argued about.

Use the buttons on each card to record your choice. They are stored in this browser only - there is no backend, no account and no network call - and you can export the whole set to CSV with the button at the bottom. Nothing in this repository changes until a decision is recorded and implemented deliberately in a later session.
