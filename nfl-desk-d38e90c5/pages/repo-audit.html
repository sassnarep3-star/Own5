Repo audit: line-by-line review of the existing NFL desks

Scope of this audit: every NFL desk already in the repository, reviewed for the properties this session was asked to deliver - official-source provenance, price snapshots, verified results, publication ordering, leaderboard separation, replacement depth, correlations with n, a demotion gate and per-row source links. Findings are recorded with file paths so they can be re-checked by hand.

Desks reviewed: nfl-desk-864d5668, nfl-desk-26d4cafb, nfl-hub-28431d9c, nfl-b34253a1, nfl-decision-desk, nfl-decision-desk-38a1fc27, nfl-decision-desk-e413f933, nfl-strategy-lab, line-lab, own5-desk, plus the shared data/ tree.

Conclusion

The repository already contains strong pieces - fail-closed validation gates, official-source discipline, injury and depth work, per-row n in correlations. The gaps are cross-desk: duplicated inputs that drift, one corrupted column, one leaderboard that mixes luck with skill, and no shared price-snapshot or verified-results layer. This desk is deliberately standalone and does not edit any file owned by another session's claim; the consolidation work is proposed as SUG-07 for a final integration session.
