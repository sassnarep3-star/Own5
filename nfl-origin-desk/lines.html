How the line is built

  1. Ratings. Ridge least squares on final margins, margin = rating_home - rating_away + HFA, fitted only on games before the week being priced. HFA = 2 points (derived 2002-2024 mean home margin).
  2. Totals. Two-way points model, points = mu + offence_team - defence_opponent, same walk-forward rule.
  3. Moneyline. Model-implied from the model spread via the documented logistic approximation (labelled; not an operator quote).
  4. Fixture context. Bye, neutral site, international, flex and rest-day features from published schedule facts only.
  5. Inputs stored. Every model output is stored as a probability-plus-inputs, not just a pick; the inputs column records the standings and HFA source.

Verification policy. Every table row links to an official page or to the script and pinned input that produced it. Values that cannot be confirmed are left blank and published on the Flagged for review page — never inferred.
