Leaderboard Competition

A standing competition rewarding repeatable, skill-based origination — not hot streaks. Repo detail: research/leaderboard.md.

Entry requirements

  1. Strategy pre-registered in repo with version hash (Gate G0).
  2. All gates G1–G8 passed.
  3. Every bet logged pre-game (timestamp, market, line/price, stake, hash). Retroactive entries void — no cherry-picking by construction.

Scoring

ComponentWeightDefinition
Shrunken CLV score70%Mean de-vigged CLV (bps), empirical-Bayes shrunk toward 0 by sample size — primary skill metric (method)
Flat-stake yield20%1-unit ROI with bootstrap 95% CI; informational, cannot rescue negative CLV
Process score10%Gate-compliance audit: timestamps, spec adherence, falsification honored

Minimums: 200 graded bets to appear; 500 to be reward-eligible (sample-size convention: source INDUSTRY, flagged).

Divisions

  • Singles — sides / totals / moneyline
  • Player props — single-leg props
  • Parlays & SGP combos — must also pass Gate G7; scored on parlay-level CLV vs the book's correlated price

Anti-gaming rules

  • Profit alone never moves rank — only shrunken CLV + process.
  • Every tried variant must be registered; the count feeds Gate G4 (DSR/PBO — Bailey & López de Prado PRIMARY). Hiding failed variants = disqualification.
  • Stake caps: ≤2% bankroll nominal; fractional Kelly enforced (Gate G8).
  • Rolling 2-season scoring window so retired edges age off.
  • Bets whose captured line/price can't be verified are excluded and listed on Flagged for Review.
