Correlation Framework — Parlays & Prop Combos

A parlay of positively correlated legs has a higher true joint probability than independence pricing implies (underpriced unless the book's "correlation tax" is big enough). Negatively correlated legs make a parlay structurally bad at any normal price. Exact reference arithmetic: five independent 50% legs ⇒ 0.5⁵ = 3.125% joint probability.

Verification notice: no official or primary source publishes numeric NBA prop-correlation coefficients. Combo-stat caution (PRA / PR / PA / RA)

A combined line (e.g., PRA 41.5) is not three independent overs: components share minutes, pace, role and game script, so you cannot sum over-probabilities or assume independence (edgebetting.ai).

How numbers get filled in

  1. Pull per-game player box scores from the official NBA statistics feed (stats.nba.com via nba_api), ≥ 2 seasons.
  2. Run analysis/prop_correlations.py — per-player (min 40 games) and league-wide Pearson/Spearman r for PTS↔AST, PTS↔REB, AST↔REB, 3PM↔PTS.
  3. Publish only with n, season range, and official source link. Everything else stays blank.
  4. Parlay pricing uses the empirical joint distribution (resampling real stat vectors preserves full dependence, not just pairwise r).
