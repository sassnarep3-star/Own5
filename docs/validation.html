Validation Gates

Every strategy must pass all gates, in order, before leaderboard entry. A strategy failing any gate returns to candidate status. Repo detail: research/nba/validation-gates.md; runnable checker: analysis/validation_gates.py (implements G3 and G5 on a logged bet CSV).

Lifecycle

Candidate → G0 pre-register → G1–G2 backtest hygiene → G5 null test → G4 multiplicity
→ paper-trade live (timestamped) → G3 CLV over ≥200 bets → G6 realism audit
→ (parlays: G7) → G8 staking plan → LEADERBOARD-ELIGIBLE

Hard rules

  • No strategy is ever graded on W/L alone — win rate needs 1,000–3,000 bets to mean anything (source, convention, flagged).
  • Every logged bet records timestamp, market, line/price at bet, de-vigged fair close, stake, strategy hash.
  • Unverifiable inputs are blank, never guessed — if lineup/injury status can't be confirmed officially at bet time, no bet.
Every table row carries a source link and tier: OFFICIAL NBA league source · PRIMARY peer-reviewed / preprint / primary author · INDUSTRY betting-industry convention (listed on Flagged for Review). Unconfirmable values are left blank — never inferred. No performance claims are made anywhere on this site.
