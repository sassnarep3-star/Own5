Review workflow

  1. Open the linked source and compare against the claim text above.
  2. If verified against an official/primary source, move the value into the relevant table with its link and remove the flag (via PR).
  3. If contradicted, delete the item from the repo entirely — do not "correct" it in place without a source.
Every table row carries a source link and tier: OFFICIAL NBA league source · PRIMARY peer-reviewed / preprint / primary author · INDUSTRY betting-industry convention (listed on Flagged for Review). Unconfirmable values are left blank — never inferred. No performance claims are made anywhere on this site.
