No official league source publishes betting lines. Spreads, totals and moneylines in this project come from a third-party consensus dataset. Every price-dependent result inherits that limitation, which is why gate G8 exists and why no prop ROI is claimed at all.

Method

StageImplementation
Line originationWeighted ridge on team indicators; exponential recency decay (300-day half-life); refit every week on strictly prior games. Separate margin and total models. Market prices are never used as model features.
Probability conversionNormal margin distribution with continuity correction for ties; residual sigma estimated from training data only.
De-viggingProportional (multiplicative) removal of overround from both sides of each two-way market.
Correlationφ coefficient for binary legs; observed joint vs product of marginals; week-clustered bootstrap intervals.
Skill vs luckExact binomial test vs realised break-even; cluster bootstrap ROI; Benjamini–Hochberg FDR at 10%; deflated Sharpe; chronological era split.
Prop linesOriginated in-repo as trailing season-to-date median (min 3 prior games). No sportsbook prop price is invented.

Reproduce

pip install -r engine/requirements.txt then python engine/run_all.py. All randomness is seeded (20261102). Tests: python -m unittest tests.test_engine.

spread_line/total_line/moneyline fields in games.csv are third-party consensus closing prices. No official league source publishes betting lines. All price-dependent results are flagged accordingly.
