Gate vocabulary

hard
a failure blocks certification outright; there is no override
soft
a failure blocks the specific claim the gate protects, not the family
MET
the test was run and passed, with the evidence in the linked file
NOT MET
the test cannot be run because the input does not exist in this repository
PARTIAL
the test was run on the subset of the universe where it is possible
